# Mitarbeit

Repository forken oder nach Einladung klonen. Mit `npm ci` installieren und `npm run dev` starten. Einen eigenen Branch anlegen, Änderungen mit `npm test` und `npm run build` prüfen und als Pull Request gegen `main` einreichen.

Originaltexte und Medienquellen respektieren. Persönliche Leserantworten bleiben privat im Browser. Keine Roman-PDF, Zugangsschlüssel oder Zugangsdaten einchecken. Online-Tests nur mit erkennbaren Testinhalten ausführen und danach die vorherigen Inhalte wiederherstellen.

Redaktionelle Änderungen können direkt über den separat geteilten Bearbeitungslink erfolgen. Änderungen an der Software erfolgen über GitHub. Backendänderungen benötigen zusätzlich ein Cloudflare-Deployment.
